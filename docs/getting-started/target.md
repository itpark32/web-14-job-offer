# Целевая роль и условия

Выберите одну основную роль на ближайший цикл поиска: **Junior Frontend Developer**. Соседние названия — Frontend Intern, Junior React Developer, Junior Web Developer. Сопоставляйте реальные задачи, а не только заголовки.

> Ищу первую Junior Frontend-позицию. Работаю с JavaScript, React и TypeScript в учебных проектах. Могу сверстать интерфейс, подключить API и обработать состояния запроса. Хочу брать небольшие продуктовые задачи с review и помощью наставника.

Это образец: оставьте только то, что подтверждено вашим кодом.

## Сопоставьте роль с доказательствами

| Роль | Что показать |
|---|---|
| Frontend Intern | Законченный небольшой сценарий, базу и способность принимать обратную связь |
| Junior Frontend | Адаптивный интерфейс, поведение на JavaScript, API и проверку результата |
| Junior React | Собственное React-приложение, объяснимые компоненты и поток данных |
| Junior Fullstack / PHP | Отдельную версию CV с серверным вкладом; Frontend остаётся основным маршрутом handbook |

Не используйте общий заголовок «Frontend / Backend / Fullstack / React / PHP Developer». Две траектории требуют двух версий резюме с одной правдивой основой.

## Выбирайте команду

В продукте спросите о пользователе и долгосрочной работе с интерфейсом. В студии — о параллельных проектах и сроках. В аутсорсе — о заказчике, review и смене проекта. В небольшой команде — кто сможет помогать junior и сколько времени у него есть. Тип компании сам по себе не гарантирует наставничество.

## Карточка цели

```text
Целевая роль:
Основной стек, который могу объяснить:
Какие задачи умею делать:
Какие задачи хочу делать:
Проекты, подтверждающие навыки:
Город / часовой пояс:
Удалёнка / гибрид / офис, часы:
Минимальные условия и допустимые компромиссы:
Личный минимум / цель по фиксу, gross или net:
Стоп-факторы:
Оформление / дата выхода:
Дата пересмотра:
```

Грейды различаются между компаниями. Уточните ожидаемую самостоятельность и тип первой задачи. Не повышайте уровень, чтобы пройти фильтр.

## Что сделать прямо сейчас

1. Заполните карточку на одной странице.
2. Подберите три вакансии с близкими задачами.
3. Для каждой ключевой задачи укажите своё доказательство.
4. Отделите стоп-факторы от пожеланий.
