# Зарплатные ожидания Junior Frontend

Определите личный минимум и целевой диапазон до звонков. Не берите общую IT-медиану за стоимость первой Frontend-работы. В этой методичке нет фиксированной рыночной вилки без свежей сопоставимой выборки.

## Как собрать ориентир

1. Возьмите актуальные вакансии одной роли и уровня из своей [выборки](../getting-started/market-2026.md).
2. Сохраните дату, ссылку, регион, формат, часы, задачи и сумму, если она указана.
3. Отделите Intern, Junior и опытные роли; не считайте дубли.
4. Отметьте gross/net, фикс/бонус. Если неизвестно — задайте вопрос.
5. Сверьте с бюджетами на реальных HR-звонках. Для [сервиса зарплат Habr Career](https://career.habr.com/salaries) проверьте фильтры, период и число анкет по [методологии](https://career.habr.com/info/salaries).

Зарплаты работающих пользователей сервиса и предложения новых вакансий — разные данные. Маленькая выборка даёт ориентир для проверки, а не оценку всего рынка.

## Личный минимум и цель

Запишите обязательные расходы, время и стоимость дороги, оборудование и приемлемую занятость. Определите минимальный гарантированный фикс для себя и диапазон для обсуждения. Нижняя граница названного диапазона должна быть приемлема.

**Gross** — сумма до налогов, **net** — после. Не пересчитывайте любую зарплату одним универсальным коэффициентом: запросите расчёт работодателя и при необходимости сверяйте актуальные правила с [ФНС](https://www.nalog.gov.ru/rn77/taxation/taxes/ndfl/). Handbook не рассчитывает индивидуальный налог.

## Фраза для HR

> Для Junior Frontend с обсуждёнными задачами рассматриваю X–Y рублей gross фиксированной части в месяц. Точная оценка зависит от занятости, формата и поддержки команды. Какой бюджет предусмотрен?

X и Y заполняются по вашим данным; это не скрытый рыночный пример. Не снижайте диапазон только из-за паузы собеседника.

Результат главы — записанные минимум, цель, условия и основания диапазона. Следующий шаг — [переговоры](negotiation.md).

## Что сделать прямо сейчас

1. Соберите сопоставимые предложения с датой и gross/net.
2. Запишите минимум для себя и диапазон обсуждения.
3. Отделите фикс от условных выплат.
4. Отрепетируйте короткую фразу ожиданий.
