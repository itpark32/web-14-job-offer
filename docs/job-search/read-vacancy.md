# Как читать Frontend-вакансию

Результат чтения — решение «откликнуться / уточнить / пропустить» с объяснением. Не считайте процент совпадения списка технологий.

## Разберите девять пунктов

| Пункт | Что искать |
|---|---|
| Задачи | Новые интерфейсы, поддержка, интеграция API, верстка, исправления |
| Обязательные технологии | На чём выполняется основная работа |
| Пожелания | «Плюсом», «желательно», соседние инструменты |
| Уровень | Самостоятельность, помощь, владение релизом |
| Опыт | Обязательный стаж или пожелание; какие задачи за ним стоят |
| Формат | Город, часы, удалёнка/гибрид/офис |
| Тестовое | Объём, срок и критерии |
| Команда | Наставник, review, взаимодействие с дизайнером и API-командой |
| Сомнительные условия | Платный доступ к вакансии, неопределённый работодатель, противоречия |

## Три группы требований

| Группа | Учебный пример | Решение |
|---|---|---|
| Жёсткое ограничение | Только офис в другом городе, а переезд невозможен | Уточнить гибкость; при конфликте пропустить |
| Ключевая работа | React + JavaScript/TypeScript для интерфейсов | Показать свой проект и готовность делать подобные задачи |
| Осваиваемое пожелание | Zustand, Redux Toolkit или Next.js «будет плюсом» | Не ждать полного совпадения; честно назвать пробел |

Значимость определяется контекстом вакансии: Redux Toolkit может быть обязательным в одной команде и пожеланием в другой.

«3+ years» нельзя всегда игнорировать. Если описаны самостоятельное владение сложным продуктом и наставничество, это существенный разрыв. Если стаж расходится с Junior-заголовком и небольшими задачами, задайте вопрос о реальных ожиданиях до затратного этапа. Не добавляйте себе годы работы.

## Карточка разбора

```text
Вакансия / URL / дата:
Три главные задачи:
Жёсткие ограничения:
Ключевые требования → мой проект и личное действие:
Пожелания → что смогу освоить:
Что неизвестно: опыт / команда / деньги / тестовое:
Решение и причина:
Следующее действие и дата:
```

Пример решения: «Откликаюсь: могу показать React-каталог и обработку API; Zustand пока не использовал, он указан как плюс. Уточню наставничество и часы пересечения».

Если основной навык пока не подтверждён ни одним проектом, назначьте короткую практику по [карте подготовки](../technical/developer.md), затем пересмотрите решение.

## Что сделать прямо сейчас

1. Разберите пять вакансий по карточке.
2. Найдите по одному доказательству ключевой задачи.
3. Задайте вопросы по ограничениям.
4. Выберите первые вакансии для адресного отклика.
