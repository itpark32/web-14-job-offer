# Какие вопросы задавать компании

Компания тоже проходит проверку. Возьмите три обязательных условия и три предпочтения из [карточки цели](../getting-started/target.md). Распределите вопросы по адресатам и просите примеры.

## Рекрутер: условия и карта отбора

Уточните бюджет и gross/net, оформление, географию, часы, офисные дни, этапы и срок решения. Спросите, почему открылась Junior Frontend-позиция. Технические детали адресуйте команде.

## Техническая команда: ежедневная работа

| Тема | Пример вопроса |
|---|---|
| Стек | React, Next или другое? Где используется TypeScript? |
| Legacy | Какая часть работы — поддержка, как вводят junior в старый код? |
| Design system / UI kit | Кто поддерживает компоненты и согласует изменения? |
| State management | Чем управляют состоянием и серверными данными? |
| API / BFF | Кто согласует контракты, где обсуждаются ошибки и изменения? |
| Code review | Кто проверит мой первый PR и как быстро приходит feedback? |
| Тесты / QA | Какие Frontend-сценарии проверяют автоматически, кто проверяет верстку? |
| CI/CD и preview | Можно ли посмотреть изменение до релиза, какие проверки обязательны? |
| Дизайнер | Как уточняются mobile, состояния и расхождения с макетом? |
| Accessibility | Какие требования проверяют и кто помогает при затруднении? |
| Релизы | Как выпускают и откатывают изменения, кто помогает при ошибке? |

Не задавайте весь список подряд. Выберите важное для этой роли и попросите пример последней задачи или релиза.

## Руководитель: первая работа и рост

- Кто мой mentor и сколько времени у него выделено на помощь?
- Как выглядит onboarding и первая задача junior?
- Какие результаты ждёте через месяц и к концу испытательного срока?
- Как часто обратная связь, кто оценивает результат?
- Как меняются задачи и оплата, какие критерии пересмотра?

Название «наставник» без человека и времени ещё не объясняет поддержку.

## Фиксируйте ответы и противоречия

| Условие | Что услышали | Следующий вопрос |
|---|---|---|
| Удалёнка | HR: «из региона», команда: «еженедельный офис» | Какой формат будет закреплён? |
| Наставник | «Помогают все» | Кто отвечает за onboarding и первый PR? |
| Пересмотр | «После испытания посмотрим» | Дата, критерии, гарантированная сумма? |

Если не называют работодателя, просят оплатить доступ к вакансии, установить неизвестное ПО или давят немедленным согласием, проверьте источник и условия до продолжения. Противоречия по обязательным пунктам разрешите до выхода.

После встречи пометьте «подтверждено / не подходит / неизвестно». Перед решением используйте [чек-лист оффера](../salary/offer.md).

## Что сделать прямо сейчас

1. Выберите пять вопросов по своим приоритетам.
2. Назначьте адресата каждому вопросу.
3. Попросите пример review, релиза и onboarding.
4. Запишите неизвестные и получите уточнения письменно.
